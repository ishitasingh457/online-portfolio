Act Fast — Emergency Preparedness App

Project Description

Act Fast is a mobile app that teaches users what to do in four major emergencies — Flooding, Earthquakes, Fires, and Intruders. I built it in MIT App Inventor using real-time weather data, API integration, and interactive quizzes to test emergency readiness. Me and my team wanted to make something that could actually assit people in stressfull and dangerous situations when something goes wrong.

My Responsibilities

I designed the app in MIT App Inventor, built the block-based logic for navigation and quizzes, integrated a live weather API, and set up the scoring system.

What I Learned

I deepened my understanding of API calls and how to handle live data in a mobile environment. I also learned how to design user flows that are intuitive under stress — an important consideration for emergency apps so they are easy to naviagte and actually use during a emergency.

Interview Questionnaire App

Project Description

An interview-based mobile app designed to gather feedback about school culture. The app contains voice-to-text recording, a calendar for scheduling, and a backend database that allows developers to export all collected user responses as CSV files for orginzation. The objective was to make collecting and analyzing school community feedback simple.

My Responsibilities

Designed and built the app from scratch in MIT App Inventor, implemented voice-to-text functionality, set up calendar integration for interview scheduling, and configured the database export pipeline that converts responses to CSV format.

What I Learned

This project taught me how to work with databases inside a mobile app and how to think about data portability, making sure the people using the data downstream can actually access it too.
